# Sistema de PPCM e Gestão de Manutenção de Frota

React + TypeScript + Vite + Firebase Authentication + Firestore + ExcelJS.

Módulos: Dashboard, Frota, Preventivas, Ordens de Serviço, Indicadores e Relatórios.

Firebase project: sistemppcmgestaofrota.

Executar: npm install && npm run dev.
Build: npm run build.
Hosting: firebase deploy --only hosting.

Não armazene senhas no GitHub. Use Firebase Authentication para criar o usuário administrativo.
